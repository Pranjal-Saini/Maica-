## Workflow

1. Inspect the current implementation and relevant contracts.
2. For non-trivial changes, write a short implementation plan.
3. Update the relevant data contract or interface first when required.
4. Implement the smallest complete change.
5. Add or update focused tests.
6. Run the relevant checks.
7. Run the full required validation before finishing.
8. Confirm that security, evidence provenance, and tenant isolation remain intact.
