## Workflow

1. Inspect the current implementation and relevant contracts.
2. For non-trivial changes, write a short implementation plan.
3. Update the data contract or interface first when required.
4. Implement the smallest complete change.
5. Add or update focused tests.
6. Run the relevant checks.
7. Confirm read-only access, evidence provenance, and tenant isolation are intact.
8. Ask whether the change moves either open question — generalisation, or willingness
   to pay. If neither, say so.
